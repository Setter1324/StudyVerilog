# StudyVerilog (KW STUDY SITE)

코드를 채우면, 회로가 걷기 시작해요. 학교 Verilog 수업(1~8주차)을 블록 마을에서 눈으로 보며 복습하는 학습 게임이다.

- 정적 웹 사이트 (Vite + React + TypeScript), GitHub Pages 배포: `https://setter1324.github.io/StudyVerilog/`
- 실행 엔진: 브라우저 안에서 도는 Icarus Verilog (WebAssembly), 서버 없음
- 기준 문서: [최종 계획 보고서](docs/KW-STUDY-SITE-최종계획서.md)

`[x]` 는 됐어요, `[ ]` 는 아직이에요. 괄호 안의 숫자는 계획서의 절 번호예요.

### 1. 지금 사이트에서 되는 것

- [x] 첫 화면: 여섯 구역이 이어진 섬 그림, 알파카가 걷는 길, "이어서 하기" 카드 (5장)
- [x] 스테이지 목록: 통과한 문제가 저장되고 새로고침해도 남아요 (브라우저에 저장)
- [x] 코드 실행: 서버 없이 내 브라우저 안에서 Verilog가 돌아요 (Icarus Verilog, 검증 통과)
- [x] 문제 6가지 유형: 예측 · 빈칸 · 버그 수정 · 변환 · 설계 · 타이밍 (8.3)
- [x] 구역 1 스테이지 15개 (초안)
- [x] 회로 위를 알파카가 걷는 재생: 바뀐 값만 차례대로, 네온 불빛 · 꼬리표 · 자막 (7.9)
- [x] 재생 조작: 처음 · 이전 · 재생 · 다음 · 끝, 속도 0.5× / 1× / 2×, 시간 슬라이더
- [x] 파형과 콘솔 출력, 그리고 맞았는지 채점 (결과 판)
- [x] 막혔을 때 도움 칸: 힌트 1 → 2 → 3 → 정답 보기 + 해설 15개 (초안) (6.3)
- [x] 자유 Verilog: 채점 없이 아무 코드나 돌려 보는 연습장 (6.4)
- [x] 효과음 (기본은 꺼짐) 과 밝은 / 어두운 테마 버튼
- [x] 끝나지 않는 코드가 사이트를 멈추지 못하게 하는 안전장치
- [x] 자동 검사와 자동 배포: 합치기 전에 문제 15개가 정답은 통과, 시작 코드는 실패하는지 컴퓨터가 확인해요

### 2. 정식 출시(v0.1.0) 전에 남은 것

**사람이 직접 해야 하는 일 (주찬)**

- [ ] 초안 문제 15개의 문구 · 정답 · 해설을 강의자료와 맞춰 보기 (0.2의 1번). 맞춘 문제는 `draft` 표시를 지워요
- [ ] 1-12 "회로도 보고 설계" 원래 문제로 바꾸기. 강의자료 18쪽 회로도를 세션에 첨부해야 해요. 지금은 같은 형식의 대신 문제예요
- [ ] 실제 사이트 주소에서 1-1, 1-4, 1-10을 직접 재생해 보고 걷는 속도가 괜찮은지 말해 주기
- [ ] 폰 화면에서도 1-1을 풀어 보기
- [ ] COM's Apps 등록 요청 (등록 문구는 주찬이 정해요)

**만들어야 하는 기능**

- [ ] 정답 · 오답 연출: 맞으면 건물이 한 번 튀고, 틀리면 알파카가 고개를 저어요 (7.8). 소리는 이미 나요

- [ ] 코드와 회로 길을 서로 눌러서 강조하기 (6.3). 지금은 파형 줄에 마우스를 올리면 길이 빛나는 것까지만 돼요
- [ ] 폰에서 코드를 고치는 문제에 "PC가 편해요" 안내 (6.1)
- [ ] 화면 자동 테스트(Playwright)를 정식 테스트로 올리기 (지금은 임시 스크립트)

## 개발

```bash
nvm use           # Node 22 (Windows는 Node 22 이상 설치)
npm install       # 처음에만. 이후에는 npm ci
npm run dev
```
